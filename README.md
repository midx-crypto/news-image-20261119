One-page newspaper image summing up Thursday 19 November 2026 world news: 25 stories in a single 1024x1024 image. Three hero stories (the Trump-Xi-Putin summit in Shenzhen, the World Court's genocide ruling on Myanmar/Rohingya, Anthropic's record IPO debut), ten more illustrated stories, a dotted world map with numbered pins, twelve one-line briefs, and a DATE CHECK footer naming big stories deliberately left out because they were first reported on 18 November. Every claim was checked against live reporting (Reuters, WSJ, CNN, UN News, Le Monde, Yonhap, ABS, IMD, AIU, Sensor Tower estimates via Forbes); estimates are labelled as estimates. The image is drawn entirely in code with Pillow by `build.py`; no photographs are used.

## Run it

python3 main.py entry.png
